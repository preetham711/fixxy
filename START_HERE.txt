IMPORTANT: FIXXY is a DESKTOP APPLICATION, not a web app!
It will open in a window on your desktop, NOT in Chrome browser.

╔══════════════════════════════════════════════════════════════════════╗
║  STEP 1: Configure MySQL Password (ONE TIME ONLY)                    ║
╚══════════════════════════════════════════════════════════════════════╝

Run this in PowerShell or Command Prompt:

    python setup_fixxy.py

Enter your MySQL root password when prompted.

╔══════════════════════════════════════════════════════════════════════╗
║  STEP 2: Run FIXXY                                                    ║
╚══════════════════════════════════════════════════════════════════════╝

Option A - Double-click this file:
    run_fixxy.bat

Option B - Run in terminal:
    python fixxy-3.py

A desktop window will open with the FIXXY application!

╔══════════════════════════════════════════════════════════════════════╗
║  STEP 3: Login                                                        ║
╚══════════════════════════════════════════════════════════════════════╝

Default admin account:
    Username: admin
    Password: admin123

╔══════════════════════════════════════════════════════════════════════╗
║  IF YOU DON'T KNOW YOUR MYSQL PASSWORD                               ║
╚══════════════════════════════════════════════════════════════════════╝

Try running this to test common passwords:
    python find_mysql_password.py

If that doesn't work, you'll need to reset your MySQL password.
See MYSQL_SETUP.md for instructions.

╔══════════════════════════════════════════════════════════════════════╗
║  ABOUT CHROME/WEB BROWSER                                             ║
╚══════════════════════════════════════════════════════════════════════╝

FIXXY cannot run in Chrome because it's built with Tkinter (desktop GUI).

However, you CAN:
✅ Export invoices as HTML and open them in Chrome
✅ Print bills from Chrome after export
✅ View the generated invoice HTML files in any browser

The main application itself runs as a desktop window.
